# Family Ops Home Assistant Add-ons

Public Home Assistant add-on repository for Azwan's personal `family-ops` infrastructure.

This repository intentionally contains only installable add-on source code. Personal data, Home Assistant API keys, GitHub registration tokens, family information, and private automation logic belong in the private `azwanmuslim/family-ops` repository or Home Assistant local configuration.

## Repository URL

Add this repository to Home Assistant:

`https://github.com/azwanmuslim/family-ops-ha-addons`

## Available add-ons

### Family Ops GitHub Runner

Dedicated GitHub Actions self-hosted runner for Home Assistant OS on Raspberry Pi 4 / aarch64.

Current release: **0.2.0**

Future releases will bump the add-on version here so Home Assistant can surface an Update button automatically.
